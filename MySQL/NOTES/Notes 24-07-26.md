\-------------------------------------------------



START TRANSACTION;



UPDATE accounts SET balance = balance + 1000 WHERE id = 1;

SAVEPOINT after\_wallet\_topup;



UPDATE accounts SET balance = balance + 10 WHERE id = 1;



ROLLBACK TO after\_wallet\_topup;

### **JOINS**

**-------------------------------------------------**



Joins are used to combine rows from two or more tables based on related columns between them



Types of Joins:



1. Innerr Join : 
2. Left Join
3. Right Join
4. Full/Outer Join





#### Inner JOIN:

\------------------------



* Common Data between both tables are printed.



**SELECT** column(s)

**FROM** tableA

**INNER JOIN** tableB

**ON** tableA.col\_name = tableB.col\_name;





* The column(s) on line 1 means what columns we want to show.



To show specific columns we do:



**SELECT** c.customer\_id, o.order\_id, c.name

**FROM** customers c

**INNER** **JOIN** orders o

**ON** c.customer\_id = o.customer\_id;





#### Left JOIN:

\------------------------



* Keeps all the data of the Left table and leaves the right table data (Common data is includes).



**SELECT** column(s)

**FROM** tableA

**LEFT JOIN** tableB

**ON** tableA.col\_name = tableB.col\_name;



Example:



**SELECT** \* 

**FROM** customers c

**LEFT JOIN** orders o

**ON** c.customer\_id = o.customer\_id;





#### Right JOIN:

\------------------------



* Keeps all the data of the Right table and leaves the Left table data (Common data is includes).



**SELECT** column(s)

**FROM** tableA

**RIGHT JOIN** tableB

**ON** tableA.col\_name = tableB.col\_name;



Example:



**SELECT** \*

**FROM** customers c

**RIGHT JOIN** orders o

**ON** c.customer\_id = o.customer\_id;







#### OUTER JOIN

\------------------------



* Ther is not keyword to perform outer join but we can obtain it by using union of left and right joins



**SELECT** \* **FROM** customers as c

**LEFT JOIN** orders as o

**ON** c.customer\_id = o.customer\_id

**UNION**

**SELECT** \* **FROM** customers as c

**RIGHT JOIN** orders as o

**ON** c.customer\_id = o.customer\_id;



Example:



**SELECT** \* 

**FROM** customers c

**LEFT JOIN** orders o

**ON** c.customer\_id = o.customer\_id

**UNION**

**SELECT** \* 

**FROM** customers c

**RIGHT JOIN** orders o

**ON** c.customer\_id = o.customer\_id;





#### CROSS JOIN

\------------------------



* Not as same as Outer join. Cross joins takes each row from left and joins it with all the rows on right. 
* Table A : 3 Rows, Table B : 2 Rows. Cross join, Takes Row 1 from Table A and joins it with each row of Table B. Same for row 2 \& 3 in Table A



**select** \* **from** customers

**cross** **join** orders;





#### SELF JOIN

\------------------------



* It is a regular join but the table is joined with itself.



Syntax:



**SELECT** column(s)

**FROM** table as a

**JOIN** table as b

**ON** a.col\_name = b.col\_name;



Example:



**SELECT** \*

**FROM** customers **as** A

**JOIN** customers **as** B

**ON** A.customer\_id = B.customer\_id;





#### EXCLUSIVE JOINS (Left/Right Excusive Join)

\------------------------



* Displaying Only the left/right part w/o the common part





**SELECT** \* 

**FROM** customers c

**LEFT JOIN** orders o

**ON** c.customer\_id = o.customer\_id

**WHERE** o.customer\_id **IS NULL**;





**SELECT** \*

**FROM** customers c

**RIGHT JOIN** orders o

**ON** c.customer\_id = o.customer\_id

**WHERE** o.customer\_id **IS NULL**;







### Sub-Queries

\-------------------------------------------------



A Subquery or Inner query or a Nested query is a query within

another SQL query. It involves 2 select statements.



Syntax



**SELECT** column(s)

**FROM** table\_name

**WHERE** col\_name operator

( subquery );





***Example - 1*** : Fetch the order amounts that are greater than the average orders amount.



SELECT \* 

FROM orders

WHERE amount > (

&#x09;SELECT avg(amount)

&#x09;from orders

);







***Example - 2*** : Fetch the count of the orders for each customer



**SELECT** name, 

&#x09;(

&#x09;	**SELECT** **count**(\*)

&#x09;	**FROM** orders o

&#x09;	**WHERE** o.customer\_id = c.customer\_id

&#x09;) **AS** order\_count

**FROM** customers c;







***Example - 3*** : Fetch customer's average spending



**SELECT**

summary.customer\_id,

summary.avg\_amount



**FROM**

&#x09;(

&#x09;	**SELECT**

&#x09;		customer\_id,

&#x09;		**AVG**(amount) **AS** avg\_amount

&#x09;	**FROM** orders

&#x09;	**GROUP** **BY** customer\_id

&#x09;) 

**AS** summary;





### Views in SQL

\-------------------------------------------------



* A view is a virtual table based on the result-set of an SQL statement.





Syntax



CREATE VIEW view1 AS

SELECT col1, col2 FROM table\_name;



\*A view always shows up-to-date data.

The database engine recreates the view,

every time a user queries it.





Views in SQL



* No data is stored physically (unless it's a materialized view in some DBs).



* Can include columns from one or more tables.



* Can be used in SELECT, JOIN, or even WHERE clauses like a normal table.



* Helps with security by exposing only certain columns to users.
