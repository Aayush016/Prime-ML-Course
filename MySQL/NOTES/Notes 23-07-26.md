### TRANSACTION

\-------------------------------------------------



#### ACID Properties:



* **Atomicity** : All statements succeed or none succeed
* **Consistency** : Data moves from one valid state to another
* **Isolation** : Parallel transactions do not interfere
* **Durability** : Committed data is permanently saved



Example: 

&#x09;	

&#x09;A -> 100 ₹ -> B }---> This whole action is treated as one Transaction. 

&#x09;Steps:

&#x09;     1. A account {-100}

&#x09;     2. B account {+100}

&#x09;If any step fails the whole transaction is failed! -> Atomicity







**Disable autocommit**

SET autocommit = 0;





**Enable autocommit**

SET autocommit = 1;

\-------------------------------------------------
